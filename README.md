## 🌟 Key Website Features

### 1. 360° Live Photo Walkthrough (Phone-Friendly)
* **True Photographic Realism:** 2048×1024 high-definition equirectangular panoramas of the Main AC Hall, Stage View, and Dining Area.
* **Mobile-Safe Scroll Trap Protection:** Interactive tap-to-start cover overlay ensures seamless thumb scrolling through the webpage without accidental gesture trapping.
* **Fluid 60 FPS Mobile Touch:** Momentum damping for natural panning, 2-finger pinch-to-zoom, and mouse wheel zoom.
* **Smartphone Motion / Gyroscope Mode:** Real-time sensor mode allows moving the physical phone to pan around the banquet hall in 360°.
* **Edge-to-Edge Fullscreen:** Native API + mobile CSS fallback for iOS Safari and Android Chrome.
* **Battery & GPU Saver:** Utilizes `IntersectionObserver` to automatically pause WebGL rendering when offscreen.
* **3D-Projected Floating Hotspots:** Dynamic pins anchored in 3D spherical space linked to real photo previews and instant WhatsApp quotation drawers.

### 2. Interactive Budget & Package Estimator
* Real-time guest count slider (200 to 1,200 guests) with dynamic tariff scaling for Silver, Gold Royal, and Platinum packages.
* Addon configuration (Sound & DJ, Theme Ambience Lighting, Valet Parking, Deep Cleaning).
* One-click *"Lock This Quote on WhatsApp"* pre-filling all package details directly to venue management.

### 3. Real Media & Social Proof Showcase
* Integrated Instagram profile card with bio, location, and follow actions for `@jkbanquets.in`.
* Real photographic highlights extracted from the venue's inauguration broadcast.
* Embedded responsive YouTube player featuring the official news telecast and hall walkthrough.

### 4. Interactive Floor Plan & Space Explorer
* Interactive architectural blueprint highlighting the Elevated Mandap Stage, Main AC Hall, Dining Hall, Green Rooms, and Entry Foyer.

### 5. High-Converting Lead Routing
* Quick date availability checker routing directly to WhatsApp.
* Main event inquiry form with client name, preferred date, event type, and notes.
* One-click *"Copy Address for Invitations"* utility with Google Maps pin navigation.
